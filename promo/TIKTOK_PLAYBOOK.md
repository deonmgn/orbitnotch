# OrbitNotch TikTok Launch Playbook

## 1. Strategi Funnel (TikTok -> Vercel -> Download / Pro)
1. **TikTok / Reels / Shorts (15–22 detik):** Tunjukkan transformasi visual Notch yang langsung berguna di atas Chrome/Spotify/Windows.
2. **Link di Bio -> Website Vercel (`orbitnotch.vercel.app`):** Pengunjung langsung melihat demo interaktif + tombol download otomatis untuk Mac (`.dmg`) & Windows (`.exe`).
3. **Monetisasi:** Gunakan **Mayar.id** / **Lynk.id** (untuk audiens Indonesia, QRIS/ewallet Rp 49.000) atau **Gumroad / Lemon Squeezy** ($6 global) untuk lisensi **OrbitNotch Pro**.

## 2. Tiga Script Video TikTok Siap Rekam

### Script 1 — Hook MacBook & Windows (Paling Viral)
- **Hook (0–3s):** *(Rekam layar laptop dengan notch biasa)*  
  Text di layar: *"Notch MacBook kamu cuma jadi hiasan? Di Windows juga bisa gini!"*
- **Demo (3–14s):**
  - Arahkan mouse ke notch -> animasi mengembang mulus di atas Chrome.
  - Drag screenshot/file masuk ke **Shelf**.
  - Klik tab **Quick**, ketik `100 usd to idr` -> langsung muncul hasil & copy.
  - Putar lagu -> equalizer bergerak, pause -> langsung berhenti seketika.
- **CTA (14–18s):** *"Namanya OrbitNotch — cuma 13 MB, gratis untuk Mac & Windows. Link ada di bio!"*

### Script 2 — Productivity Hack (Screenshot & Mirror)
- **Hook (0–3s):** *"Cara kirim screenshot ke WhatsApp & cek muka sebelum Zoom dalam 1 detik."*
- **Demo (3–15s):**
  - Ambil screenshot -> otomatis muncul badge `Screenshot` di Notch!
  - Hover notch -> klik Copy Image -> paste di WhatsApp/Chrome.
  - Pindah ke tab **Meet** -> klik **Mirror** buat cek kamera & mic.
- **CTA (15–18s):** *"Download OrbitNotch di link bio, tersedia versi Mac & Windows."*

### Script 3 — Behind the Scenes / Dev Story
- **Hook (0–3s):** *"Aku bikin aplikasi Dynamic Island untuk Mac & Windows dari nol."*
- **Demo (3–16s):** Tunjukkan proses coding singkat + hasil akhir notch menyatu sempurna tanpa garis tepi di atas aplikasi lain.
- **CTA (16–20s):** *"Coba gratis sekarang di link bio — kasih masukan fitur apa lagi yang mau ditambah!"*
